# Не спи — лента

Три новые страшные истории каждый день в 17:30 по Душанбе для Android-приложения «Не спи».
Все истории придуманы и написаны Claude.

- `index.json` — список плёнок.
- `editions/<дата>.json` — плёнка дня.
- `registry.json` — реестр всех сюжетов, чтобы истории никогда не повторялись.
